# Промт: добавить проект в портфолио

Скопируйте текст ниже в чат с Claude, где открыт репозиторий нужного проекта.

---

Добавь этот проект в моё портфолио — репозиторий **0oda0/portfolio** — в том же формате, что уже есть там для Studio Booking.

1. Подключи репозиторий `0oda0/portfolio` (add_repo, доступ на запись) и прочитай `docs/PROJECT_SCHEMA.md` и пример `projects/studio-booking/project.json`.
2. Разберись в текущем проекте: для кого он, какие роли пользователей, какие экраны, какая бизнес-логика и правила (расчёты, ограничения, автоматика, защита данных).
3. Запусти проект локально с **демо-данными** (вымышленные имена и телефоны; если сида нет — создай временные данные, не меняя код проекта). Если проект нельзя запустить — сначала спроси меня.
4. Сними скриншоты Playwright'ом: 1280×800, JPEG качество ~78, все ключевые экраны каждой роли; длинные страницы — дополнительно во весь рост (`full`); 1–2 снимка с телефона 390×844 и один в тёмной теме, если она есть. Положи их в `projects/<slug>/img/`.
5. Напиши `projects/<slug>/project.json`: hero с тезисом и 3–4 фактами (только реальные цифры), схема пути пользователя (`flow`), главы по ролям, у каждого экрана — что на нём происходит и 2–5 пунктов «Бизнес-логика», блок автоматики/защиты, адаптация (`gallery`) и таблица внедрения или стоимости, если уместно. Пиши по-русски, просто и конкретно, без выдуманных метрик.
6. Добавь slug в `projects/index.json`, запусти `node scripts/check.js` — должно быть `OK`. Открой `project.html?p=<slug>` через `node serve.js` и проверь, что всё отображается.
7. Закоммить и отправь в ветку **main**: `git pull --rebase origin main`, при конфликте в `projects/index.json` оставь в списке все проекты (свой — в конец), снова `node scripts/check.js`, затем `git push origin main`. Если push в main запрещён — отправь в отдельную ветку и скажи мне, что её нужно влить.

Запрещено: пароли, токены, ключи, IP серверов, реальные данные клиентов и названия компаний заказчиков без моего разрешения.
